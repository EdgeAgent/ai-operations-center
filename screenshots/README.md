# Dashboard screenshot placeholders

This concept repository does not include a running dashboard or production screenshots. The following slots are reserved for future mockups or screenshots built with synthetic data:

- `overview-dashboard.png` — overall health, recent activity, and items needing attention.
- `workflow-analytics.png` — n8n execution trends and failure summary.
- `usage-and-costs.png` — token usage and clearly labeled cost estimates.

Before publishing screenshots, use synthetic data and remove credentials, customer content, tenant identifiers, internal URLs, and unapproved business metrics. Do not present a mockup as a live product capture.
